# Collection FR — Mihon

Add this repository in Mihon:

`https://raw.githubusercontent.com/anderson76389/collection-fr/main/repo.json`

The store contains only the eleven French sources listed below. GitHub Actions refreshes the extension index daily from the published Keiyoushi repository. APK downloads remain on Keiyoushi's release host and retain the matching Keiyoushi signing key.

- AnimeSama
- Astral-Manga
- Dassou Scan
- Japscan
- Manga-Scantrad
- Mangas-Origines.fr
- Rimu Scans
- Scan-Manga
- Scan Reader
- Scan VF
- Sushiscan.fr

**Known upstream issue:** the currently published Scan-Manga extension has a reported search failure caused by an invalid subdomain. A fixed upstream release will flow into this store automatically.
