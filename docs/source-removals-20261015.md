# Retrait des cinq extensions demandé le 15 octobre 2026

Les modules suivants sont retirés du code actif, de la compilation et du catalogue Mihon :

| Extension | Ancien module |
| --- | --- |
| MangaK | `src/all/mangabuddy` |
| BDPlus | `src/fr/bdplus` |
| HistoireDHentai | `src/fr/histoiredhentai` |
| Flixnet (CoffeeManga) | `src/all/flixnetcoffeemanga` |
| MangaDot | `src/fr/mangadotnet` |

Les 34 autres modules sont conservés sans modification, dont Mangakawaii, qui est distinct de MangaK. Toutes les bibliothèques partagées, notamment `lib-multisrc/mangak`, sont conservées.

Les rapports d'ajout antérieurs décrivent des vérifications historiques ; ils ne constituent pas la liste actuelle des extensions publiées. Les anciennes versions restent dans l'historique Git et les anciennes Releases. Une extension déjà installée sur un téléphone doit être désinstallée depuis ce téléphone.
